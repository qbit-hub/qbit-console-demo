# Qbit Console Demo

This public repository contains generated browser artifacts for the Qbit Console demo.

- The application source remains in the private `qbit-console-web` repository.
- Files in this repository are generated from the validated `main` revision of that source repository.
- Do not edit generated site files manually; the publishing workflow replaces them automatically.
- The demo is static and browser-only. It does not connect to the Qbit backend, PostgreSQL, or production ZITADEL.

The deployed artifact intentionally contains only files that a browser must download to run the demo, plus deployment metadata and this repository's GitHub Pages workflow.
